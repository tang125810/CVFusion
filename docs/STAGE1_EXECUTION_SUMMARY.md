## 2. 评估口径（本次统一的尺子）

- 官方 View-of-Delft devkit 协议（SGDet3D 随附副本，直接 import，不改写）；
- **精确 float64 旋转 IoU**（Sutherland–Hodgman；原 devkit/OpenPCDet 的 RRPN 同源 float32 核在近重合框上会漏顶点，同一权重差约 +0.3 mAP）；
- 1296 帧验证集，Entire / ROI(Driving Corridor) / not-ROI 三区域，三类，R11 与 R40；
- 自检：把原始标签当作预测输入，三个区域 × 三类 × R11/R40 的 3D/BEV AP 全为 **100.0000**。

**口径换算**：既有文档里的 52.5843（项目自带 CUDA IoU）在本口径下是 **52.27**；本文所有数字均为本口径。

## 4. 唯一被采纳的改动

论文只写了图像特征 `F_I` 的分辨率是 H/4，**没有写 Swin-T 的截取位置**。原实现取 `features[:2]`
（patch embedding + stage 0）。本次改为：完整冻结 Swin-T，stage 0/1/2/3 各接 1×1 侧向卷积到 96 通道，
双线性上采样到 H/4 后拼接，3×3 卷积融回 96 通道。深度头、图像投影、视角变换、RGIter、anchor、
NMS、损失、调度、随机种子、4 卡 × batch 2 全部未动，输出张量形状一致 `(B, 96, 96, 152)`。

代价：融合模块可训练参数 1.09M → 1.56M，单 epoch 时间 +4%。

**边界**：这证明“骨干截取位置”是真实缺口，不证明作者用的就是该聚合形式；Car 仍是主要缺口。

| 方向 | 判定 | 依据 |

| 采样式视角转换（体素中心反向采样 + `grid_sample`） | ❌ 否决 | 同 epoch 全程落后基线 1.4–3.0 mAP（epoch 10–55），提前终止于 epoch 55 |
| 推理期图像消融当作 radar-only 精度 | ❌ 不成立 | 常量帧使 mAP 崩塌到 4.96，是分布偏移；已改为真正的 radar-only 重训（见 §6） |
| 完整 PV-RCNN 式 BEV RPN / 高度注意力 | ❌ 沿用项目既有结论 | 历史实验 52.58 → 49.75（同口径约 52.27 → 49.5） |
| 论文外辅助损失（深度/门控监督） | ❌ 沿用项目既有结论 | 历史两轮 guided fine-tune 均掉分 |

## 6. 进行中与待补

| 实验 | 目的 | 状态与结果 |
|---|---|---|
| radar-only 重训（`VT_MODE: zero`，无相机分支） | 判断剩余缺口在雷达骨干还是相机融合 | ✅ 诊断完成（跑到 epoch 52 终止）。**相机增益**：旧图像特征 +3.1~+4.6 mAP，imgmulti **+9.4~+10.3 mAP**；论文是 +10.4（concat）/ +13.0（Stage1）。radar-only 外推收敛约 47~48，与论文雷达单模态 46.7 同量级 → **缺口在相机侧，不在雷达骨干** |
| VoD 拟合 anchor（三类同改） | 修复实测的 anchor 覆盖不足（行人 60.0%、骑行者 70.9%） | ❌ 否决：epoch 5/10/15 = +5.1/-5.7/-7.2 mAP，差距持续扩大，epoch 15 后终止 |
| Car-only 底面高度（-1.78 → -0.8 m） | 针对新诊断出的 Car 竖直定位误差 | ❌ 否决：epoch 10/15/20 = -3.6/-6.7/-3.9 mAP，无收敛趋势 |
| 匹配改用 3D IoU（`MATCH_HEIGHT: True`） | 让正样本必须竖直一致，直接针对 Car 的竖直误差模式 | ❌ 否决：epoch 5/10/15 = +2.2/-1.3/-5.8 mAP |

三项 anchor/匹配类改动（三类同改 anchor、Car-only 底面高度、3D IoU 匹配）都呈现"epoch 5 领先、epoch 10–15 落后"的同一形态且无追赶趋势，按规则全部否决。**判据边界**：它们改的是学习目标而非特征，而 OneCycle 学习率到 epoch 32 才达峰，因此早期窗口对它们更严格；结论应读作"在 epoch 10–20 窗口内未显示收益"，若复审需跑满 80 epoch 加至少两个种子。

### 6.1 Car 缺口的最终定位（下一阶段课题）

| 现象 | 数据 |
|---|---|
| Car 3D AP 与 BEV AP 的落差 | 42.82 vs 52.84（差 10.0） |
| "BEV 合格但 3D 不合格"的 GT | **422 / 4291**（Pedestrian 216、Cyclist 36） |
| 其中底面高度误差 | 中位 -0.238 m，**68% 超过 0.3 m** |
| 其中车长误差 | 中位 +0.036 m，49% 超过 0.3 m |
| 距离分布 | 72% 在 25 m 以外 |

即：**Car 不缺候选，缺的是远处车辆的竖直定位精度**。换 anchor 先验无效（模型已学会那约 1 m 的常量偏移），下一步应针对距离相关的回归精度（按距离分桶加权、或引入高度/深度显式监督）做单变量实验——这超出本文件六步排查的范围。
| 完整两阶段（PGF/GGF） | 论文完整模型 65.41 / 82.42 的对照 | 本次未重训；既有权重官方口径 Entire 58.57 / ROI 73.41 |
